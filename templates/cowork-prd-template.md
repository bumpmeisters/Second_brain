# Cowork PRD Template

## 1. Purpose

What should this cowork system or module help with?

## 2. Users and jobs

Who uses it, and what jobs should it complete?

## 3. Source boundaries

What can it read?

What should it never modify?

What should it treat as unverified?

## 4. Outputs

What should it create or update?

Where should outputs live?

## 5. Operating rules

When should it ask for clarification?

When should it push back?

When should it require explicit approval?

## 6. Data layer

What data, folders, registers, logs, or dashboards are needed before the module can work?

## 7. Workflow

What are the steps from request to finished output?

## 8. Evaluation

What does a good result look like?

What examples should be tested?

What failure modes should be checked?

## 9. Permissions and safety

Which tools or folders can it use?

Which actions are forbidden?

How should failures be logged?

## 10. Build plan

What should be built first?

What can wait for a later iteration?
