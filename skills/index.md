# Skills Index

Local skill system for reusable AI work patterns in this vault.

## AI Work Blueprint System

- `ai-work-blueprint/` - Main orchestrator skill for meaningful AI tasks: create a spec, define verification, execute the first slice, and update the environment.
- `ai-spec-builder/` - Build a clear, small, reviewable spec from a vague task.
- `ai-output-verifier/` - Review an AI output against criteria, evidence, risks, and external signals.
- `ai-environment-updater/` - Convert repeated workflow lessons into durable templates, wiki pages, rules, or future skills.

## Notes

- `repository-analysis/` - Explore selected external repositories, preserve exact snapshots, and create task-discoverable learning dossiers. Repo examples: `repositories/index.md` from the vault root.

- Each skill lives in its own folder and has a required `SKILL.md`.
- These skills are stored inside the vault for local reuse and iteration.
- When a skill proves broadly useful, consider installing or copying it into the main Codex skills directory.
