# Web Scraping Tools

**Summary**: The source lists repositories for AI crawling, Markdown extraction, browser automation, scraping frameworks, reconnaissance crawling, and no-code scraping.

---

Crawl4AI is described as an AI-powered crawler for LLM pipelines that extracts clean structured data (source: Post by @cyrilXBT on X.md).

Firecrawl is described as turning websites into clean Markdown for AI consumption and RAG pipelines (source: Post by @cyrilXBT on X.md).

Scrapy is described as a Python scraping framework with more than 50,000 stars (source: Post by @cyrilXBT on X.md).

Crawlee is described as a framework wrapping Playwright and Puppeteer with built-in anti-detection features (source: Post by @cyrilXBT on X.md).

Playwright is described as Microsoft's browser automation library for JavaScript-heavy sites (source: Post by @cyrilXBT on X.md).

ScrapeGraph AI is described as using LLMs to navigate and extract data with natural language instructions (source: Post by @cyrilXBT on X.md).

Browser Use is described as giving AI agents browser control (source: Post by @cyrilXBT on X.md).

Katana is described as a reconnaissance crawler for security researchers (source: Post by @cyrilXBT on X.md).

Maxun is described as a no-code web scraping platform (source: Post by @cyrilXBT on X.md).
