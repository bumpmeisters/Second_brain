# Prompt Engineering Research

**Summary**: Research cluster for general prompting patterns, advanced prompting techniques, and reusable prompt playbooks.

---

The prompting fundamentals folder contains 32 files and is the largest single section in the AI prompting research library (source: research/assets/06_AI_Prompting/01_Prompting_Fundamentals; analysis: wiki/_outputs/ai-research-ingest-2026-06-03.json).

The sources appear to focus on advanced prompting techniques, prompt structure, comparison across model outputs, and broad prompt playbooks. Because many files are AI-generated or model-specific, use the folder for pattern discovery rather than verified model behavior (source: research/assets/06_AI_Prompting/01_Prompting_Fundamentals; analysis: [[ai-research-validation]]).

## Useful Leads

- Compare different model outputs for the same prompt before turning a pattern into a standard.
- Preserve prompts together with task context, desired output shape, constraints, and evaluation criteria.
- Treat "best prompting technique" claims as time-sensitive unless backed by current official guidance or repeatable local tests.
