# Failure-Trajectory Evaluation Source Brief

**Summary**: An Anthropic product leader describes converting vague user complaints into reproducible failure trajectories and task-specific regression cases.

## Durable pattern

Translate user feedback into the observed trajectory, classify the failure mechanism, reproduce it under controlled conditions, add representative and counterbalancing cases to a versioned evaluation set, and use that set to test future system changes. Broad PRDs still serve alignment when the product problem is ambiguous; evals do not replace that function.
