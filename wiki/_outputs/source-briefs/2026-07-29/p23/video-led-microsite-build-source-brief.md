# Video-Led Microsite Build Contract

## Core thesis

The clipping supplies an unusually complete production prompt for turning one existing video and a concept into a scroll-driven commercial microsite. Its reusable contribution is the build contract: staged creative direction, fixed media custody, narrative chapters, implementation constraints, accessibility, error handling, an auto-tour control, reconstruction documentation, and a build-success requirement.

## Structured outline

1. Generate several video-led commercial concepts.
2. Convert one concept into a precise continuous-motion video prompt.
3. Provide the finished video filename and concept to the site-building contract.
4. Derive brand, offer, conversion goal, narrative, visual system, and motion language.
5. Build a full-screen scroll-video experience with synchronized chapters.
6. Add smooth scrolling, manual controls, reduced-motion behavior, loading and media fallbacks.
7. Preserve a reconstruction prompt on a dedicated route and require a successful production build.

## Reusable mechanisms

- Separate ideation, media creation, and website implementation into explicit stages.
- Treat the supplied media as immutable and read its real runtime rather than assuming duration.
- Bind interaction and interface language to the physical narrative of the film.
- State routes, architecture, responsive behavior, accessibility, cleanup, browser behavior, and verification as acceptance criteria.
- Preserve the creative and technical reconstruction brief with the finished experience.

## Caveats

Generated copy, claims, brand decisions, code, accessibility, performance, licensing, security, and regulated-category language still require human and technical review.
