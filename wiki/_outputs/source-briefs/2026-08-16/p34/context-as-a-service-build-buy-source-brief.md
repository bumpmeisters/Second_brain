# Context-as-a-Service Build/Buy — Source Brief

**Summary**: A Bright Data talk compares ad-hoc search, vertical context services, and an owned web-data pipeline for recurring entity research.

## Useful contribution

The durable decision variable is recurrence: rented search or context is useful for variable questions, while repeated questions about the same entities can justify an owned collection layer when freshness, scope, coverage, maintenance, permissions, reliability, and repeated cost support it (source: 2026-08-14--Ot4OPrPH4xY.md).

## Decision and limits

`extended-claim` for [[ai-operating-system]]. The talk calls its exercise a test rather than a benchmark. Vendor scale, decay percentages, one-day build claims, provider rankings, zero-cost retrieval, and the fixed crossover estimate are excluded.
