# Xirp Parallel-Agent Supervision Source Brief

**Summary**: A product-centered practitioner demonstration of supervising many coding-agent sessions through one visible surface. Its durable delta is narrow: isolate concurrent repository work, expose state and resource use, and use event hooks to bring only defined exceptions back to the human.

## Durable signal

- Separate concurrent coding sessions with worktrees so agents do not edit the same working copy.
- Keep running, blocked, action-needed, and completed states visible to the supervisor.
- Route defined events to a notification or audit channel instead of requiring constant polling.
