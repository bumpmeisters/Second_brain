# Raw Sources

Dieser Ordner enthält von Stefan bereitgestellte Originalquellen. Claude darf sie lesen, aber niemals verändern, verschieben oder löschen.

Für v0.1 gilt Deutschlandmodus `no customer recording`:

- keine Kundenstimme;
- keine Live-Gesprächsaufnahme;
- kein daraus erzeugtes Transkript;
- optional nur Stefans eigene, nach Gesprächsende aufgenommene Selbstreflexion;
- personenbezogene und vertrauliche Inhalte auch darin minimieren.

Neue Dateien zunächst in `raw/inbox/` ablegen. Vor inhaltlicher Nutzung Herkunft, Berechtigung, Zweck und Speicherort prüfen.
