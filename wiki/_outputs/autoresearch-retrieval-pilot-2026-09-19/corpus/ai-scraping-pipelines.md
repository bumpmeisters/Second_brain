# AI Scraping Pipelines

**Summary**: AI scraping pipelines collect, render, clean, or structure web content so it can be used by LLMs and RAG systems.

---

The source connects Crawl4AI to LLM pipelines and structured data extraction (source: Post by @cyrilXBT on X.md).

The source connects Firecrawl to clean Markdown output for AI consumption and [[rag]] pipelines (source: Post by @cyrilXBT on X.md).

The source connects ScrapeGraph AI to LLM-based navigation and extraction from natural language instructions (source: Post by @cyrilXBT on X.md).

Browser Use is positioned as a way to let AI agents control a browser, which can support agent-driven browsing or scraping workflows (source: Post by @cyrilXBT on X.md).
