# Obsidian Plugins

**Summary**: The recommended Obsidian plugin stack is Templater, Dataview, Tasks, QuickAdd, and Obsidian Git.

---

Templater is recommended for dynamic templates that insert dates, times, note titles, and variables (source: The Obsidian Vault Setup That Replaced My $500 Per Month Software Stack.md).

Dataview is recommended for querying notes and tasks across the vault like a database (source: The Obsidian Vault Setup That Replaced My $500 Per Month Software Stack.md).

Tasks is recommended for due dates, recurrence rules, priorities, and task queries inside notes (source: The Obsidian Vault Setup That Replaced My $500 Per Month Software Stack.md).

QuickAdd is recommended for fast capture into specific vault locations with a keyboard shortcut (source: The Obsidian Vault Setup That Replaced My $500 Per Month Software Stack.md).

Obsidian Git is recommended for automatic backups to a private GitHub repository (source: The Obsidian Vault Setup That Replaced My $500 Per Month Software Stack.md).
