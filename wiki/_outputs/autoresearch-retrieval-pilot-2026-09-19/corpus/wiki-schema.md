# Wiki Schema

**Summary**: The wiki schema is the rules file that tells the AI agent how to maintain the wiki.

---

The source describes the schema as a rules document that tells the AI how to structure pages, handle new sources, format output, and answer questions (source: Karpathy's LLM Wiki - Full Beginner Setup Guide.md).

In the tutorial, this rules file is called `claude.md` for Claude Code (source: Karpathy's LLM Wiki - Full Beginner Setup Guide.md).

In this workspace, `AGENTS.md` is the canonical Codex [[wiki-schema]] because it defines folders, ingest behavior, page format, citation rules, question answering, linting, and rules (source: Karpathy's LLM Wiki - Full Beginner Setup Guide.md).

The older `agent.md` file is kept as a compatibility pointer to `AGENTS.md` (source: Karpathy's LLM Wiki - Full Beginner Setup Guide.md).
