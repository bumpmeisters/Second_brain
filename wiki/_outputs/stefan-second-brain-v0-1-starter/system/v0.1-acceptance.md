# Abnahme v0.1

## Technische Basis

- [ ] Claude Code lädt `CLAUDE.md`.
- [ ] `.claude/settings.json` wird geladen.
- [ ] Claude kann `raw/` nicht verändern.
- [ ] Der Validator läuft ohne Fehler.
- [ ] Git-Baseline und getrenntes Backup-Ziel existieren.

## Wissensdurchstich

- [ ] Mindestens eine reale Quelle liegt unverändert in `raw/`.
- [ ] Eine Quellenzusammenfassung verweist auf den Originalpfad.
- [ ] Mindestens ein Claim ist nachvollziehbar mit der Quelle verbunden.
- [ ] Belegstärke und Evidenzart wurden geprüft.
- [ ] Ein Kontextpaket verwendet nur relevante Claims.
- [ ] Ein Lehrartefakt verweist maschinenlesbar auf seine Claims.

## Governance-Test

- [ ] Eine ungeprüfte KI-Aussage bleibt B0.
- [ ] Ein Sekundärreferat bleibt als solches sichtbar.
- [ ] Ein Widerspruch wird ergänzt statt überschrieben.
- [ ] Eine Rückstufung findet das abhängige Artefakt.
- [ ] Vertraulichkeit wurde vor Modellverarbeitung geprüft.

## Nutzungstest

- [ ] Stefan kann selbst eine Quelle ablegen.
- [ ] Stefan kann die Herkunft einer Folienaussage finden.
- [ ] Stefan kann eine Wiki-Frage stellen und Unsicherheit erkennen.
- [ ] Eine 45-Minuten-Probeeinheit wurde durchgeführt oder aufgezeichnet.
- [ ] Retrospektive und Entscheidungen für v0.2 sind dokumentiert.
