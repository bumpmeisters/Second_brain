# Project Delivery Tracking

**Summary**: Project delivery tracking uses trackers, timelines, Gantt views, milestones, tasks, and team context to manage campaign or marketing execution.

---

The project-management folder contains delivery trackers, timeline templates, milestone/task spreadsheets, and one XLSB project plan that was cataloged but not deeply extracted (source: raw/assets/08_Reporting_und_Ops/Project_Management).

The delivery tracker files include project team and Gantt/timeline structures (source: Project_delivery_tracker.xlsx; source: Project_delivery_tracker_.xlsx).

The timeline templates provide milestone and task views for planning project schedules (source: Milestone and task project timeline.xlsx; source: Project timeline with milestones.xlsx).
