## Selection protocol

1. Match the current task against the `Use when` column.
2. Reject candidates whose `Avoid when` condition applies.
3. Prefer the smallest sufficient set; do not load adjacent practices without a concrete need.
4. Open the selected artifact and treat its body, sources, guardrails, and reuse boundaries as authoritative.
5. If no artifact fits, continue without forcing a match and record a reusable gap only when it recurs.

## Skill-promotion rule

Keep practices as wiki artifacts by default. Consider promotion to a local skill only after repeated real use shows that the artifact needs active agent routing, tools, templates, or deterministic verification. Promotion requires explicit review; frequency alone does not authorize it.
