# Obsidian

**Summary**: Obsidian is used as a local Markdown viewer, editor, and graph interface for the wiki and vault.

**Sources**: raw/Clippings/Karpathy's LLM Wiki - Full Beginner Setup Guide.md; raw/Clippings/The Obsidian Vault Setup That Replaced My $500 Per Month Software Stack.md.

**Last updated**: 2026-05-30

---

The LLM wiki source says [[obsidian]] is a free note-taking app that works with plain Markdown files (source: Karpathy's LLM Wiki - Full Beginner Setup Guide.md).

The Obsidian setup source says Obsidian notes are plain Markdown files stored locally and can be opened in any text editor (source: The Obsidian Vault Setup That Replaced My $500 Per Month Software Stack.md).

The LLM wiki source uses Obsidian mainly as the visual interface for the agent-maintained wiki and graph view (source: Karpathy's LLM Wiki - Full Beginner Setup Guide.md).

The Obsidian setup source uses Obsidian as a full personal knowledge and productivity system with folders, templates, plugins, and review workflows (source: The Obsidian Vault Setup That Replaced My $500 Per Month Software Stack.md).
