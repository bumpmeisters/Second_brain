# Daily Workflow

**Summary**: The daily workflow uses a daily note to set priorities, capture throughout the day, and close the loop in the evening.

**Sources**: raw/Clippings/The Obsidian Vault Setup That Replaced My $500 Per Month Software Stack.md.

**Last updated**: 2026-05-30

---

The source recommends starting the morning daily note with three priorities before checking email or chat tools (source: The Obsidian Vault Setup That Replaced My $500 Per Month Software Stack.md).

During the day, the source recommends capturing ideas, tasks, lookups, and call notes into the daily note first (source: The Obsidian Vault Setup That Replaced My $500 Per Month Software Stack.md).

In the evening, the source recommends spending about 10 minutes marking completed work, moving unfinished tasks, and sending important captures to the inbox for later processing (source: The Obsidian Vault Setup That Replaced My $500 Per Month Software Stack.md).
