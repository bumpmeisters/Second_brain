# Storytelling Frameworks

**Summary**: Storytelling frameworks provide reusable structures for campaign narratives, B2B thought leadership, and marketing message development.

---

The storytelling folder contains B2B storytelling framework research, marketing storytelling framework analysis, ChatGPT/Gemini/O3-generated framework documents, and thought-leader storytelling framework research (source: raw/assets/05_Content/Storytelling_Frameworks).

Because several files appear to be AI-generated or AI-assisted, claims from these sources should be treated as framework hypotheses until verified or validated by expert judgment (source: raw/assets/05_Content/Storytelling_Frameworks/20250419_B2B Storytelling Frameworks Research_O3.docx; source: raw/assets/05_Content/Storytelling_Frameworks/20250419_Marketing Storytelling Frameworks Analysis_Gemini.docx).
