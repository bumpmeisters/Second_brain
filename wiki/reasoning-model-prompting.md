# Reasoning Model Prompting

**Summary**: Research cluster for prompting reasoning models, o-series style models, and tasks that require deliberate problem solving.

---

The reasoning models folder contains five files, including a notebook and files that mention o-series prompting and reasoning model prompt design (source: research/assets/06_AI_Prompting/07_Reasoning_Models; analysis: wiki/_outputs/ai-research-ingest-2026-06-03.json).

Model-specific prompting guidance is especially time-sensitive. Treat this page as a pointer to research files, not as current official guidance for any model family (source: research/assets/06_AI_Prompting/07_Reasoning_Models; analysis: [[ai-research-validation]]).

## Useful Leads

- Prefer clear task decomposition, constraints, and success criteria over hidden reasoning instructions.
- Test model-specific advice on representative tasks before standardizing it.
- Link reasoning-model prompts to [[deep-research-workflows]] when the task involves research synthesis.
