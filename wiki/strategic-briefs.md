# Strategic Briefs

## P57: Herkunft von Positionierungs- und Nutzeninputs

Ein Brief soll getrennt ausweisen, ob ein Input bestehende Kommunikation, gemessene Kundenwahrnehmung oder eine zukünftige Option beschreibt. Die passende Prüfung liefern [[positioning-communication-audit]], [[perceptual-positioning-analysis]] und [[value-proposition-analysis]]. Annahmen, Belege und zulässige Verwendung mitübergeben; ein Canvas oder eine Formulierung ist kein Marktbeleg. Eigene Handoff-Synthese aus (source: research/2026-09-14-framework-source-verification-p57.md).

**Summary**: Strategic briefs help position products, campaigns, portfolios, or communication plans in a way that guides creative and go-to-market execution.

---

The HP strategic brief folder contains communication planning, an older strategic brief template, and a value proposition/GTM value proposition template (source: raw/assets/09_Beispiele_HP/Strategic brief).

The HP briefs summary says strategic briefs can help position related products relative to each other and support GTM value proposition work (source: raw/assets/09_Beispiele_HP/Agency brief HP/Briefs Summary.pptx).
