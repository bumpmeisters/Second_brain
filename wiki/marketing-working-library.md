# Marketing Working Library

**Summary**: Source summary for `raw/assets/B_MKT_working_library`, the active marketing work library covering strategy, brand/company material, content/social/PR, campaigns and missions, operations, sales enablement, and presentations/meeting preparation.

---

This bundle contains 1,011 cataloged files across the working library, including one README file and seven major workstream folders (source: raw/assets/B_MKT_working_library; analysis: wiki/_outputs/raw-assets-new-marketing-inventory-2026-06-05.md).

The working library is different from the smaller [[frameworks-templates-reference-library]]: it contains active project work, multiple iterations, drafts, final versions, AI-generated variants, presentations, meeting notes, campaign artifacts, web downloads, audio/video files, and operational assets (source: raw/assets/B_MKT_working_library).

The largest areas are `04_Campaigns_Missions_and_Projects` with 422 files and `01_Strategy_and_Planning` with 371 files, followed by `06_Sales_and_Buyer_Enablement` with 117 files (source: raw/assets/B_MKT_working_library; analysis: wiki/_outputs/raw-assets-new-marketing-inventory-2026-06-05.md).

Filename dates are important in this library: 661 files include a date-like prefix, and 228 files include version signals such as final, draft, master, copy, prompt, Gemini, ChatGPT, GPT5, O3, or Genspark (analysis: wiki/_outputs/raw-assets-new-marketing-file-inventory-2026-06-05.csv).

## Caveats

- This is an inventory-level ingest for a large mixed folder; not every `.docx`, `.pptx`, `.pdf`, spreadsheet, `.msg`, audio/video, archive, web-download file, or extensionless file was deeply extracted (analysis: wiki/_outputs/raw-assets-new-marketing-inventory-2026-06-05.md).
- Some filenames contain future-looking dates relative to 2026-06-05 or malformed date strings such as `2023-00-29`; treat filename dates as provenance clues, not verified calendar facts (analysis: wiki/_outputs/raw-assets-new-marketing-file-inventory-2026-06-05.csv).
- AI-labeled, model-labeled, or prompt-labeled files are useful leads and working artifacts, not verified source truth unless independently checked (source: raw/assets/B_MKT_working_library; source: AGENTS.md).
