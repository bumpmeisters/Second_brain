# RAG

**Summary**: Retrieval augmented generation is described as a document-question workflow that retrieves relevant chunks at answer time.

**Sources**: raw/Clippings/Karpathy's LLM Wiki - Full Beginner Setup Guide.md; raw/Clippings/Post by @cyrilXBT on X.md.

**Last updated**: 2026-05-30

---

The LLM wiki source defines [[rag]] as a workflow where an AI searches uploaded files, retrieves relevant chunks, and generates an answer (source: Karpathy's LLM Wiki - Full Beginner Setup Guide.md).

The source argues that [[rag]] can fall short when questions require connecting ideas across multiple documents because the AI repeats retrieval and synthesis each time (source: Karpathy's LLM Wiki - Full Beginner Setup Guide.md).

Firecrawl is described as converting websites into clean Markdown for RAG pipelines, making it relevant to [[ai-scraping-pipelines]] (source: Post by @cyrilXBT on X.md).
