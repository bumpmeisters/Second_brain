# AI Project Agent

This project is Rolf's thematic source project for durable AI knowledge work and source-owned content. It turns governed references from the Second Brain into bounded context, positions, Creative Directions, briefs, assets, and learning records without duplicating the vault's canonical evidence layer.

## Scope

The project uses five navigational tracks:

1. Foundations and Model Behavior
2. Agentic Systems
3. Applied AI
4. Safety and Governance
5. Frontier and Futures

Tracks are not child projects. Create a separate project only after Rolf explicitly decides that a track needs its own purpose, evidence custody, output cadence, decision owner, or approval boundary.

## Ownership

- Root-vault `raw/`, `research/`, and `wiki/` artifacts remain canonical in their existing locations.
- Reference canonical upstream artifacts; do not copy them into this project.
- This project owns AI-topic context packets, content positions, Strategic Creative Directions, briefs, assets, approvals, pilot records, and performance records.
- Store Content Operating System objects under `authority/`.
- Never modify `raw/`, `raw/assets/`, `research/assets/`, or source clippings.

## Evidence rules

- Separate primary research, first-party explanation, independent replication, secondary reporting, AI-generated research, project analysis, and Rolf's judgment.
- Sources from the same author or research release are one evidence family, not independent corroboration.
- Treat model capabilities, product behavior, regulation, and frontier claims as time-sensitive.
- Do not turn functional similarities between AI models and humans into claims of subjective experience or consciousness.
- Unsupported or unresolved statements remain hypotheses or excluded claims.

## Content Operating System

Use `projects/content-operating-system/` for the lifecycle contract:

```text
referenced AI context
  -> Strategic Creative Direction
  -> Content Brief
  -> content asset
  -> truthful publication state
  -> bounded learning
```

- Context packets must not choose the final thesis, angle, narrative route, hook, format, or copy.
- Creative Direction owns the optional Personal Take Checkpoint.
- Execution may change expression but not approved meaning or evidence boundaries.
- Drafting and review never authorize publication.
- Publishing, posting, sending, uploading, scheduling, or external sharing always requires a separate direct instruction naming the exact asset and channel.

## Working rules

- Work in German with Rolf unless a specific asset requires another language.
- Prefer one active topic and one bounded pilot at a time.
- Keep project structure small; add folders only when real work requires them.
- Record uncertainty, rights, confidentiality, freshness, and approval state explicitly.
