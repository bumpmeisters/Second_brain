# AI

**Summary**: Rolf's thematic source project for understanding AI, developing evidence-bounded points of view, and creating source-owned content without duplicating the Second Brain's canonical evidence layer.

---

## Purpose

The project connects existing AI knowledge in the vault to governed content work. Canonical sources and wiki synthesis stay in their existing locations; this project owns the decisions and artifacts created from them.

## Topic map

| Track | Scope |
|---|---|
| Foundations and Model Behavior | LLM mechanisms, emergence, reasoning, interpretability, and consciousness boundaries. |
| Agentic Systems | Agents, harnesses, tools, context, memory, evaluation, and security. |
| Applied AI | Use cases, adoption, AI-supported work, AI for marketing, and problem-centered observation of relevant AI application vendors. |
| Safety and Governance | Alignment, controls, accountability, regulation, and societal risk. |
| Frontier and Futures | AGI, ASI, frontier labs, capability paths, and strategic implications. |

These tracks are navigation aids, not child projects.
