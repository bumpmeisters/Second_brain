# Company Workspaces Agent

This directory is an inactive neutral boundary for future company-owned workspaces. The root `AGENTS.md` remains fully controlling. No company or thematic workspace has been admitted, moved, or activated here.

## Current authority

- This shell has no operational or canonical authority.
- Do not create a child workspace, move an existing project, or route company work here without an exact separately approved change set.
- Do not relocate, copy, rename, rewrite, or delete any source, extraction, evidence record, company asset, approval, run record, or learning record.
- Do not create a local raw library, research library, source register, shared framework library, shared skill library, connector store, or credential store.
- Existing embedded company workspaces and the fourteen protected Raw objects remain untouched pending their exact later decisions.

## Target boundary after activation

An individually approved company or thematic workspace may own its concrete:

- context and analysis artifacts;
- Brand Core and positioning decisions;
- GTM and campaign decisions;
- content directions, briefs, assets, and approvals;
- run manifests, performance records, and episodic learnings.

Root Second Brain continues to own source custody and durable shared knowledge. Shared systems continue to own reusable methods and contracts. A source workspace must reference those owners rather than duplicate them.

## Instruction inheritance

- This file provides the neutral container boundary only.
- A child workspace receives its own `AGENTS.md` only when a distinct source, confidentiality, permission, or operating boundary is reviewed and justified.
- A child instruction may narrow access or add safeguards; it may never weaken root source, evidence, security, or approval rules.
- Company-specific integrations require a named data owner, permission contract, secret boundary, side-effect policy, retention rule, disable path, and explicit approval before use.

## Activation gate

Every first workspace requires an exact custody manifest, source-retention decision, target path, reference-impact review, acceptance tests, and rollback plan. This shell does not satisfy that gate.
