# Company Workspaces

**Summary**: An inactive neutral container for future company and thematic source-project workspaces.

## Current maturity

Checkpoint P2A created only this README and the local `AGENTS.md`. There are no admitted child workspaces, active project routes, duplicated assets, local sources, integrations, or canonical decisions here.

Existing company workspaces remain at their current paths. In particular, P2A does not relocate the embedded projects or protected Raw objects inside `projects/No and low code_1st Marketing Agent/`.

## Intended ownership model after activation

```text
Root Second Brain
  owns source custody and durable shared knowledge

Shared marketing systems
  own reusable methods and cross-system contracts

Company or thematic workspace
  owns concrete context, decisions, assets, approvals, runs, and episodes
```

This separation prevents company evidence and strategic assets from becoming implementation details of ContextOps, ABM, Content OS, or the Marketing Operating System umbrella.

## Admission requirements

Each proposed child workspace needs a separately reviewed change set defining:

- exact source and asset custody;
- confidentiality and permission boundaries;
- the canonical location of each concrete artifact;
- links to shared methods without editable copies;
- integration and secret ownership when applicable;
- reference transition, validation, and rollback evidence.

Until such a checkpoint is approved, this container is not a destination for files or work.
