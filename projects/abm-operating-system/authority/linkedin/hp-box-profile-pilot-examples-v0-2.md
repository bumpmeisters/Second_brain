Wer sich noch fragt, warum Drucker überhaupt in eine Security-Diskussion gehören, braucht zuerst eine Antwort auf diese Frage. Ein Produktvergleich setzt schon einen Schritt weiter an.

Genau diese Reihenfolge steckte hinter dem Box Model, das ich 2019 für ein HP-Kampagnenkonzept entwickelte. Das damalige Briefing ging von geringer Problemerkennung aus. Deshalb bekam das Produkt die letzte von fünf Boxen:

Problem verstehen → Verbindung zu HP erklären → Bewertungskriterien entwickeln → Präferenz begründen → passendes Portfolio zeigen.

Die zweite Box sollte beispielsweise die Brücke von Drucker-Security zur gemeinsamen Betrachtung von PCs und Druckern schlagen. Damit ließ sich erklären, warum HP für diese Frage relevant war, bevor einzelne Produkte ins Spiel kamen.

Heute würde ich die erste Box an einem konkreten Arbeitsauftrag festmachen. Ein möglicher Artikeltitel wäre: „Sind unsere Drucker Teil unseres Security-Konzepts?“

Im Briefing dazu würde stehen:

Der Leser soll anschließend erklären können, warum er Drucker in seine Sicherheitsprüfung einbeziehen sollte. Der Artikel muss diese Relevanz anhand überprüfbarer technischer Quellen erläutern. Produktvergleiche bleiben draußen. Eine benannte fachlich verantwortliche Person prüft die Aussagen. Erst wenn die Problemfrage verständlich beantwortet ist, schließt der nächste Inhalt an.

Damit wären sechs Dinge geklärt: die gewünschte Veränderung beim Käufer, die Belege, die Aufgabe des Inhalts, seine Grenzen, die Verantwortung und der Übergang.

Rückblickend war meine Architektur damals weiter als meine Fähigkeit, sie für die Arbeit einer Agentur ausreichend präzise zu beschreiben. Heute würde ich solche Aufträge pro Box ergänzen. Das ist mein Lernpunkt aus der Konzeption; eine gemessene Kampagnenwirkung leite ich daraus nicht ab.

Und die Reihenfolge gilt nicht für jeden Käufer. Wer sein Problem bereits kennt und Lösungen vergleicht, braucht Produktinformationen früher.

Beim nächsten Kampagnenbriefing würde ich eine Box herausgreifen: Könnte ein Team daraus einen Inhalt entwickeln, ohne die eigentliche Aufgabe erst erraten zu müssen?
