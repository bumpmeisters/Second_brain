## Operating model

```text
Source evidence
      ↓
Blueprint Challenge Record
      ↓
Candidate Pattern
      ↓
Human Promotion Decision
      ↓
Enterprise Growth System
      ↓
Consulting and Authority Derivatives
      ↓
New Evidence
```

The private knowledge system and the public authority platform are connected but not interchangeable. Real-company cases remain approval-gated even when their source material is public or non-sensitive.

## Ownership boundaries

- The parent vault owns immutable sources, sidecars, and the global source register.
- This project owns the only editable Enterprise Growth System following Gate G2 approval.
- This project owns its concrete Content Operating System objects under `authority/directions/` and `authority/briefs/`; the shared Content Operating System owns only their contracts, frameworks, workflows, and publication register.
- The Marketing Agent will consume the canonical framework through a direct cross-project reference and will not keep a local release copy.
- Shared Marketing Agent history stays in its existing logs; ABM-specific forward records begin only after an approved cutover.
