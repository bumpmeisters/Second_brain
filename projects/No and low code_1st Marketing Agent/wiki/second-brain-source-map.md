## How To Use This Map

- Start with the company evidence, not the framework.
- Search the local `frameworks/` library first.
- Use these parent pages only when the local library has a genuine gap or a framework needs improvement.
- Prefer a small set of relevant frameworks over a large generic framework dump.
- Record why a framework was selected, rejected, or adapted.
- Curate reusable frameworks into `frameworks/` using `frameworks/framework-document-standard.md`.
