# Framework Output Map

Map selected frameworks to concrete artifacts.

| Canonical framework area | Best output |
|---|---|
| Market Analysis | Market boundary, alternative set, structural force note. |
| Segmentation | Segmentation strategy packet and validation signals. |
| Claim Governance | Claim matrix, approved language, blocked claims. |
| Audience Understanding | Audience question, language, objection, proof, and trust maps. |
| Positioning | Message house, proof pillars, value proposition. |
| Journey And GTM | Journey map, campaign architecture, sales enablement. |
| Growth And Planning | Funnel diagnosis, lifecycle map, growth loop, OGSM. |
| Orchestration And Learning | Handoff contract, retrospective, pattern and improvement backlog. |

## Output Rule

For each selected framework, state:

- Why it fits.
- What it enables next.
- What input is still missing.
- Whether it should be used now or later.
