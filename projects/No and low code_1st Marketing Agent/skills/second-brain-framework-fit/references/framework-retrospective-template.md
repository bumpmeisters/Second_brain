# Framework Retrospective Template

Use after a company/product run to improve framework selection.

```markdown
# Framework Retrospective

## Frameworks Used

| Framework | Stage used | Helpfulness | Why |
|---|---|---:|---|

## Frameworks Deferred

| Framework | Why deferred | Use later when |
|---|---|---|

## What Transferred Well

- ...

## What Was Too Generic

- ...

## New Pattern

- When [condition], use [framework] to produce [artifact].

## Skill Or Workflow Improvement

- ...
```

## Helpfulness Scale

| Score | Meaning |
|---:|---|
| 1 | Distracting or premature. |
| 2 | Mildly useful but generic. |
| 3 | Useful with adaptation. |
| 4 | Strong fit. |
| 5 | Essential to quality or trust. |
