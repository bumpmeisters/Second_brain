# Framework Selection Rules

Use frameworks after company context exists.

## Selection Criteria

Select a framework when it:

- Directly answers the user's current goal.
- Fits the evidence state and risk level.
- Enables a concrete next artifact.
- Adds structure the agent would otherwise improvise.
- Can be applied without pretending unsupported facts are known.

Defer a framework when it:

- Requires missing inputs.
- Would produce generic advice.
- Belongs later in the sequence.
- Is too broad for the current decision.
- Would turn weak claims into strategy prematurely.
