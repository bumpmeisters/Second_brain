# Quality Rubric

Score each category from 1 to 5.

| Category | 1 | 3 | 5 |
|---|---|---|---|
| Trust | Mostly unsupported | Key claims sourced, gaps visible | Fully auditable, contradictions handled |
| Usefulness | Generic | Applies to company context | Immediately guides decisions or execution |
| Completeness | Major stage missing | Covers requested scope | Covers scope plus next evidence needs |
| Actionability | Abstract | Has next steps | Clear owners, artifacts, validation path |
| Reusability | One-off | Some reusable structure | Pattern can improve future runs |

## Review Questions

- What would make this output unsafe or misleading?
- What would the user need next to act on it?
- Which part should become a workflow, skill, template, or tool?
- Which assumptions should be tested in the next company run?
