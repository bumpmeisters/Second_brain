# Evidence Gap Template

Use this checklist when source intake reveals missing evidence.

## Common Gap Categories

| Category | Questions |
|---|---|
| Product identity | What is the exact product, version, SKU, package, or plan? |
| Intended use | What does the official documentation say the product/service is for? |
| Proof | What evidence supports performance, safety, ROI, or outcome claims? |
| Customer | Who buys, uses, influences, and blocks adoption? |
| Market | What market/category does the company compete in? |
| Competitors | Which alternatives are direct, indirect, or status quo? |
| Commercial | What is the pricing, packaging, margin, sales model, and channel model? |
| Regulatory | What approvals, certifications, standards, or legal limits apply? |
| Recency | Which claims are time-sensitive and need current verification? |
| Bias | Which sources are self-promotional, sponsored, generated, or incomplete? |
