# Workflows

Repeatable procedures and acceptance criteria for the marketing-agent project.

## Core Workflows

- [Company Context Development](company-context-development.md): end-to-end staged company context and strategy workflow.
- [Marketing Agent Runbook](marketing-agent-runbook.md): how to execute a company/product run using the local skills.
- [Wiki Maintenance Audit](wiki-maintenance-audit.md): recurring checks for source integrity, citations, stale claims, and link structure.

## Workflow Rules

- Put procedures here when they should be human-readable and tool-neutral.
- Promote a workflow into a skill only after it repeats and needs agent-specific routing.
- Promote a workflow step into `tools/` only when deterministic execution is safer than prose.
