# Growth Loop Analysis

## Framework Job

Identify repeatable systems where the output of one cycle becomes an input that drives the next cycle.

## Classification And Fidelity

Adapted from Reforge growth-loop practice. ContextOps evidence and loop-validity tests are project additions.

## Use When

- Retention, referral, content, supply, UGC, network, or repeat-purchase dynamics may compound.

## Do Not Use When

- A sequence has no self-reinforcing return path.

## Minimum Required Inputs

- Actors, actions, outputs, reinvestment path, conversion data, delay, and constraints.

## Core Model

Map input, action, output, reinvestment, and loop conversion. Distinguish acquisition funnels from genuine loops.

## Question Engine

### Minimum Viable Questions

- What input starts the cycle?
- What actor performs which action?
- What output is created?
- How does the output create a new input?
- What conversion occurs at each step?
- What delay weakens the loop?
- What constraint caps growth?
- Is the loop observable in data?

### Deepening Questions

- Who captures the value?
- Which step has the lowest conversion?
- Does quality decay as volume grows?

### Counter-Questions

- Is this merely a funnel with an arrow back?
- Does the output actually recruit or retain the next participant?
- What external subsidy keeps the loop alive?

### Optional Modules

- Referral.
- UGC/content.
- Repeat occasion.
- Marketplace/network.

## Branching And Stop Rules

If no measurable reinvestment path exists, classify it as a funnel or lifecycle sequence, not a loop.

## Evidence Standard

Use cohort, referral, repeat, content, network, and conversion data.

## Business-Model Adaptations

- B2B: referrals, product usage, collaboration, partner loops.
- D2C: reviews, UGC, gifting, repeat occasion, bundles.
- Marketplace: cross-side liquidity and supply/demand loops.

## Output Contract

Loop diagram, actors, conversions, delay, constraint, metrics, evidence, and experiments.

## Failure Modes

Loop labeling without recurrence, ignoring saturation, and optimizing one step while degrading quality.

## ContextOps Handoff

Feeds growth strategy and measurement after core proposition and funnel work.
