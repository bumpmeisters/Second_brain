# Orchestration And Learning Frameworks

| Framework | Primary contribution | Evidence requirement | Main risk |
|---|---|---|---|
| [ContextOps Stage Contract](contextops-stage-contract.md) | Defines inputs, outputs, boundaries, evidence, and handoff for one context stage. | Upstream artifact and downstream need. | Bureaucratic fields without a real handoff. |
| [Evidence-Led Recursive Learning](evidence-led-recursive-learning.md) | Converts completed work into reusable patterns and controlled system improvements. | Completed artifacts, user feedback, and observed friction. | Generalizing from one case. |
