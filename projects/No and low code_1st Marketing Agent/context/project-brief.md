# Project Brief

This project is a local-first second brain and operating environment for a no-code/low-code-first marketing agent.

The agent accepts company names, URLs, uploaded documents, and documents about a company. It builds trustworthy company context across offer, positioning, market, competition, customers, segmentation, sales, and marketing strategy.

The project uses the initializer pattern from `20260614_agent-project-initializer-starter-system.md`: keep `AGENTS.md` canonical, keep `CLAUDE.md` thin, split repeatable work into workflows and skills, preserve evidence, and log decisions.

## Source Priority

1. User-provided company documents and official company URLs.
2. The project-local `frameworks/` folder as the canonical execution library.
3. Rolf's existing Second Brain for framework discovery and improvement when the local library has a gap.
4. Reputable primary or current external sources when facts are time-sensitive or high-stakes.
5. AI-generated research as leads only until verified.

## Output Goal

The default durable output is an auditable company workspace under `projects/<Company>/` with source summaries, company context, strategy outputs, source registers, and logs.
