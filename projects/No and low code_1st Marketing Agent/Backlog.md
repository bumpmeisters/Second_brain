## Operating Rule

Use this promotion logic:

1. **Idea** - captured here because it may matter later.
2. **Candidate** - appears useful in one real case or repeated conversation.
3. **Draft artifact** - create a framework, workflow, output, or skill only when the job is clear.
4. **Active system component** - promote only after validation, handoff quality, and source/provenance checks.

## Current Idea: Creative Execution Layer

The Human-Led Creative Marketing Loop now exists as a draft framework. Do not create a large umbrella skill yet.

Better future direction: create a narrow downstream skill only after the framework has been tested in at least one real project case.

### Candidate Skill: `creative-strategy-execution`

Purpose: translate upstream strategy into creative territories, hooks, narrative routes, and testable variants.

Should consume:

- company/source context;
- audience or buying-context packet;
- segmentation strategy if target logic matters;
- proof-led positioning or message house;
- claim matrix, approved language, and blocked claims;
- campaign role architecture;
- brand, channel, legal, and measurement constraints.

Should produce:

- human seed card;
- creative territory map;
- divergent concept batches;
- strategic convergence scorecard;
- narrative route recommendation;
- hook options;
- pre-mortem and claim-risk notes;
- testable creative variants;
- handoff questions for production or testing.

Stop rules:

- Stop if upstream context is missing.
- Stop if high-risk claims have not passed claim governance.
- Stop before final external copy approval.
- Do not invent customer truth or claim proof.

Why not build now: the draft framework has not yet been applied to a real project case.

## Possible Future Skill System Around Creative Work

Only consider this if creative execution becomes a repeated project stage.

### 1. `creative-strategy-execution`

Role: concepting layer.

Creates creative territories, narratives, hooks, and test variants from approved context.

### 2. `content-drafting`

Role: production layer.

Turns an approved concept and narrative route into draft copy or content assets while preserving claim boundaries, brand voice, and channel constraints.

Possible outputs:

- LinkedIn post drafts;
- email drafts;
- landing-page sections;
- ad variants;
- content outlines;
- campaign copy blocks.

Critical caveat: this skill should not choose the creative strategy. It should draft from an approved concept.

### 3. `campaign-testing-plan`

Role: experimentation layer.

Converts creative variants into a test plan with hypothesis, changed variable, held-constant elements, success metric, disconfirming result, and learning to preserve.

Possible outputs:

- A/B test brief;
- paid-social variant plan;
- email subject/body test;
- PDP creative test;
- landing-page message test.

Critical caveat: do not invent performance benchmarks without data.

### 4. `creative-performance-learning`

Role: recursive learning layer.

After campaign or content performance is available, extract reusable lessons for audiences, claims, hooks, narratives, channels, and future creative directions.

Possible outputs:

- creative learning note;
- winning/losing pattern table;
- message-risk update;
- framework improvement proposal;
- reusable prompt/template refinement.

Critical caveat: do not generalize from one weak test. Route major pattern changes into recursive learning and framework improvement backlog.

## Guardrails For Future Me

- A mega-skill is tempting. Resist it.
- Prefer narrow skills that consume and produce clear ContextOps artifacts.
- If a skill starts doing strategy, drafting, testing, and learning at once, split it.
- A framework should improve reasoning; a workflow should order repeatable work; a skill should guide a repeatable agent behavior; a tool should perform deterministic checks.
- Keep AI-generated research as leads, not evidence.
- Preserve human taste and judgment in creative work.
- Do not let polished AI language bypass claim governance.
- Do not promote ideas because they are elegant. Promote them because they repeatedly solve a real problem.
