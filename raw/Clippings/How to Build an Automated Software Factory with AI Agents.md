02Step-by-Step Guide

1

### Conduct the 'Morning Build' Briefing

Start your day by collaborating with an AI in Claude. Use a simple prompt to kick off a conversation about what to build next for your application.

```
morning build
```

2

### Initiate Build & Review Agent Loops

In Claude Code, set up two separate, continuously running agent loops. The 'Build Loop' takes the task list and writes the code for features, while the 'Review Loop' picks up completed tasks, reviews the code, and makes corrections.

3

### Send Preview Notification to Slack

Once a feature is built and reviewed by the AI agents, configure the system to send a notification to a designated Slack channel. The message must include a link to a preview deployment on a service like Vercel for testing.

4

### Test the Live Preview

Click the Vercel link from the Slack message to test the new feature in a live, sandboxed environment. Verify that it works as expected.

5

### Approve Deployment with an Emoji

If the feature is ready to ship, simply react to the Slack message containing the preview link with a 🚀 emoji. This action will serve as the trigger for the final step.

Pro Tip: The emoji acts as the human-in-the-loop approval, making deployment fast and simple.

6

### Trigger Automated Merge and Deploy

Set up a final agent that monitors the Slack channel for the 🚀 emoji reaction. When it detects the emoji on an approval message, it automatically merges the code into the main branch and deploys the feature.
