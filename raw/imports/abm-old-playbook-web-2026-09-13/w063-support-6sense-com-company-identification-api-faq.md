#### Where can I learn more about 6sense API offering?

Refer to [6sense API Portal](https://api.6sense.com/docs/).

#### Will the Company Identification API slow down my page load?

Not at all! The API is designed to load asynchronously and in the background.

#### How fast is the response time for the Company Identification API?

Generally under 150ms depending on location, with under 50ms not uncommon in US. It is production ready and built to scale and has already been deployed on hundreds of pages without issue.

#### Can you do both client-side and server-side implementations?

Yes. For implementation details please refer to the 6sense Company Identification API documentation.

#### I want to self-serve an integration with \_\_\_\_\_\_\_\_\_\_. Can 6sense do it?

The answer is dependent on the solution and business constraints and sometimes requires development work but is most likely yes. In general, any service that accepts custom code being run on their platform will most likely be able to work.

#### I’m on my mobile cellular network, will the API work?

Your cellular network will have an IP address that belongs to a cell company (like ATT). The API will most likely identify the mobile visitor as your mobile provider.

#### What’s the best place the API will work?

Generally at your company office campus, especially your HQ.

#### I’m in my Company’s HQ, why is the data identifying me as a different company?

It’s likely that we are identifying the previous tenant/occupant of your HQ. It’s also likely that you share a block of IPs from another tenant in the building. It’s also likely that your ISP has made a recent change.

#### What is your match rate?

6sense delivers one of the highest match rate in the industry. The match rate depends on the type of traffic you are seeing. For example: If the website is primarily B2B, software and tech, and US based, it can be as high as 75%. However, we are constantly making improvements to our data to boost the match rate so please don’t hesitate to give us feedback.

#### Why is the data incorrect?

6sense has the best in house data scientists, but we are only as good as our data that we receive. Furthermore, as we get our data from data vendors, we are at the mercy at how quickly the data vendors update them. Our machine learning algorithm is constantly getting better and will self-correct as we see more intent data on the B2B network.

#### How often does the firmographic data update?

6sense gets its data from data vendors generally monthly or quarterly.

#### Why is the API usage match rate shown in **Reports** > **Usage** lower than expected?

The Usage Report uses a straightforward calculation:

**Actionable Matches ÷ Total API Calls**

Because this calculation includes **all API calls**, it also includes calls that result in non-actionable matches.

Non-actionable matches are included in the Usage Report because the API request was still processed.

Non-actionable matches refer to matched pageviews that cannot be used for B2B purposes. These include pageviews associated with traffic that does not reliably map back to a company name or domain, such as traffic generated by bots, VPNs, proxies, cloud infrastructure, or other noisy signals. As a result, non-actionable matches are no longer considered a subset of valid pageviews.

The match rate ultimately reflects the type of visitors the website attracts. A lower match rate typically indicates that the website is receiving a high volume of traffic from IP addresses that 6sense correctly identifies as non-actionable. Common examples include VPN traffic, AWS and other cloud servers, 5G/4G networks, and bots. While we have information on these IP addresses, they cannot be reliably associated with a company and therefore cannot be used for B2B use cases.
