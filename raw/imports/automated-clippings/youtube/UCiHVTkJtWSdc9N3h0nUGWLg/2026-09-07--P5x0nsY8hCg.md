# Stop Building AI Agents With Workflows

## Creator description

How to enable agents on self-hosted instances 👉 https://go.n8n.io/pgNQWO

In this video, @liammcgarrigle explains where first-class agents fit within n8n's AI offering, when to use them instead of a workflow, and how the two work together.

Agents are useful for tasks without fixed, predefined steps. Give an agent objectives, personality, skills, and tools, then let it decide how to complete the task. You can limit which tools it can access or require human approval before certain actions. Agents can also work where your team already does, for example in Slack.

Workflows give you deterministic logic that runs the same way every time. You can also add AI to a workflow for specific steps such as classification, filling out data, or tasks that need tools and multiple layers of AI.

You don't have to choose one or the other. Workflows can become tools for agents, and agents can be called from the workflow canvas. This lets you combine agent autonomy with visible, controlled workflow logic.
